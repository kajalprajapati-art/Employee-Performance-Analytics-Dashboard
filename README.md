# Employee-Performance-Analytics-Dashboard
Employee Performance Analytics Dashboard  Developed an Excel-based Employee Performance Analytics Dashboard to analyze employee productivity, achievement, quality scores, task completion, attendance, and overall performance across departments and regions.
Analyzed employee productivity, achievement, and quality performance.
Compared performance across departments and regions.
Evaluated target vs. completed and pending tasks.
Analyzed attendance, working hours, and overtime.
Classified employees based on overall performance status.
Created pivot tables and dashboard views to identify performance trends and key insights.

Tools Used: Microsoft Excel, Pivot Tables, Data Analysis, Dashboard
